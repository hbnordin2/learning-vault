# Retrieval is reconstruction

Retrieving information from memory is not a passive read-out of a stored copy. Memory is reconstructive: a recalled item is rebuilt from partial traces and the schema it is fitted into (Bartlett, 1932), and the act of rebuilding it changes the stored trace. This is the reason [[The testing effect|retrieval practice]] improves retention, and the reason it is often mistaken for mere assessment — the act of recalling strengthens memory more than re-reading does (Roediger & Karpicke 2006). By analogy to computing, retrieval resembles a recompute that writes its result back, rather than a read that leaves the store unchanged.

## The mechanism is debated; the effect is not

One candidate mechanism is reconsolidation: a retrieved memory becomes briefly labile and must be re-stored, creating a window in which it can be strengthened or altered (Nader, Schafe & LeDoux, 2000, in rats; Hupbach et al., 2007, in humans). Other accounts — elaborative-retrieval, episodic-context, and bifurcation models — compete with it. The phenomenon, that retrieval produces more durable memory than restudy, is established by meta-analysis; the underlying mechanism is not settled.

## The benefit depends on retrieval difficulty

Effortful but successful retrieval strengthens memory more than easy retrieval, following the storage-strength and retrieval-strength relationship described in [[How memory works]]. An item recalled immediately after study produces little gain; the same item recalled after a delay, once access has decayed, produces a larger one. Spacing exploits this: the interval between sessions sets the difficulty of the next retrieval (see [[The spacing effect]]). A review scheduled too soon adds little.

## Recognition is not retrieval

Identifying an answer when it is shown produces little of the strengthening effect, because no reconstruction takes place. Recall, in which the answer is generated, produces more durable memory than recognition, in which it is selected from options. For flashcards, this means the answer must be produced from memory before the card is turned over. Turning the card over and confirming a sense of familiarity is recognition, and is the most common reason self-testing fails to work.

## Reconstruction also makes memory fallible

Because retrieval rebuilds a memory rather than replaying it, it can rebuild it incorrectly. The same process that allows retrieval to strengthen memory also allows it to be distorted: the misinformation effect and false-memory research show that information present at the time of retrieval can reshape what is recalled (Loftus, 2005). One practical consequence is that repeated retrieval of an error, without correction, reinforces the error — which is the basis for the feedback requirement noted in [[The testing effect]].
